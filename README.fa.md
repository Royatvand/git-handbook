## درباره‌ی پروژه

این مخزن یک مرجع آموزشی برای یادگیری Git است؛ با تمرکز بر فهمیدن دلیل هر دستور، تمرین عملی و استفاده‌ی امن از تاریخچه‌ی پروژه. هدف فقط حفظ‌کردن فرمان‌ها نیست، بلکه باید بتوانید پیش‌بینی کنید هر دستور چه تغییری ایجاد می‌کند و هنگام اشتباه چطور وضعیت را بازیابی کنید.

## از کجا شروع کنم؟

- **تازه‌کار هستید؟** از [آموزش جامع فارسی](./Git-Zero-to-Hero-FA.md) شروع کنید.
- **راهنمای انگلیسی می‌خواهید؟** [Git: Zero to Hero](./Git-Zero-to-Hero-EN.md) را بخوانید.
- **می‌خواهید مشارکت کنید؟** ابتدا [راهنمای مشارکت](./CONTRIBUTING.md) را ببینید.

## موضوعات آموزشی

- مفاهیم پایه: Repository، Working Directory، Staging Area و Commit
- ساخت مخزن و مدیریت تاریخچه‌ی تغییرات
- کار با Branch، Merge، Rebase و حل تعارض‌ها
- اتصال Remote و استفاده از Clone، Fetch، Pull و Push
- بازیابی تغییرات با Restore، Revert، Reset و Reflog
- ابزارهای پیشرفته مانند Stash، Tag، Cherry-pick و Bisect
- همکاری تیمی، Pull Request، Code Review و آشنایی با GitHub Actions
- اشتباهات متداول، دستورهای کاربردی و مسیر پیشنهادی تمرین

## روش پیشنهادی مطالعه

۱. هر بار یک بخش را بخوانید و دستورها را واقعاً اجرا کنید.  
۲. یک پوشه یا Repository آزمایشی بسازید تا اشتباه‌ها آسیبی به پروژه‌ی اصلی نزنند.  
۳. پیش از Commit یا بازگردانی تغییرات، از `git status` و `git diff` استفاده کنید.  
۴. ساخت Branch، حل Merge Conflict و بازیابی را عملاً تمرین کنید.  
۵. به‌جای حفظ‌کردن دستورها، دلیل استفاده و پیامد آن‌ها را یاد بگیرید.

> **هشدار:** دستورهایی مثل `git reset --hard`، `git clean -fd` و Force Push ممکن است کار شما یا هم‌تیمی‌هایتان را از بین ببرند. قبل از اجرا، وضعیت پروژه را بررسی کنید و روی کاری که نمی‌توانید از دست بدهید آزمایش نکنید.

## مشارکت در پروژه

اصلاح خطاهای نگارشی، شفاف‌تر کردن توضیحات، افزودن مثال و گزارش دستورهای مشکل‌دار خوش‌آمد است. لطفاً پیش از ارسال تغییر، [راهنمای مشارکت](./CONTRIBUTING.md) را مطالعه کنید. هیچ‌وقت رمز عبور، Token، کلید خصوصی یا اطلاعات حساس را به مخزن اضافه نکنید.
